One line, 95 characters: a deadpan one-star review of sleep — **Sleep: one star. Takes eight hours a day and I still wake up tired. Cancelling my subscription.**

The program writes that line to `entry.txt`, gated to the competition's rules (UTF-8, 1–160 characters, single line, not whitespace-only), so the entry is valid before it ever reaches the judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-star-output python3 main.py
```

Writes the review to `entry.txt` in the output directory (or `output/` when `MAKEFUN_OUTPUT_DIR` is unset). Python 3.13, standard library only, deterministic — no network, no randomness, no clock.
